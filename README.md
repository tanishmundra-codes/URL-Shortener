# 🔗 NanoUrl

A full-stack URL shortener with analytics, user authentication, and mobile support.

**Live Demo:** [https://nano-url-three.vercel.app](https://nano-url-three.vercel.app)

## 🛠 Tech Stack
* **Frontend:** React, Tailwind CSS, Vercel Analytics
* **Backend:** Node.js, Express
* **Database:** PostgreSQL
